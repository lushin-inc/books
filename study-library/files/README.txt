Each book gets its own folder here, named with the book's slug.
Inside each folder, drop the four deliverables with these EXACT names:

    spoken.docx     Spoken Companion   (Word / Speechify)
    insights.pdf    Insights + Action Guide
    images.pdf      Concept Atlas      (images only)
    audio.pdf       Atlas Audio Companion  (Speechify)

Optional:
    cover.jpg       cover image for the tile (also set  cover:true  on the book)

The folders for the 14 seeded books are already here. To add a new book,
make a new folder here whose name matches the slug you put in the BOOKS
list in index.html.
